Nook

Everything Nook does runs on this device.

Translation

Select text on a page, then pick Translate selection from the right-click menu or press the shortcut below. The translation appears under the text.

Quality varies by language. It was measured for French, German, Spanish, Vietnamese, Ukrainian, Polish, Japanese, Chinese and Tagalog; translations into Japanese, Chinese and Tagalog are noticeably weaker. The other languages haven't been measured yet.

Sites where translation is off

Translation model

Nook translates with a language model that runs on this device's graphics processor. The model is downloaded once, from Hugging Face. That download is the only time Nook uses the network; the text you translate never leaves this device.

Model

The model loads again in a second or two the next time you translate.

Tab tools

Group tabs by site, close duplicate tabs and undo the last change, from the toolbar icon's right-click menu, a tab's right-click menu, or the shortcuts below.
